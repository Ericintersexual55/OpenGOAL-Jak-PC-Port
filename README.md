# Jak 3 PC Port

> **Jak 3** — Epic action-adventure game where Jak and Daxter fight to save the world from dark forces in vast deserts, futuristic cities, and dangerous wastelands.

[![Stars](https://img.shields.io/github/stars/Mathifygaming/OpenGOAL-Jak-PC-Port)](https://github.com/Mathifygaming/OpenGOAL-Jak-PC-Port) [![License: MIT](https://img.shields.io/badge/License-MIT-orange.svg)](https://opensource.org/licenses/MIT)

**Jak 3 PC Port** is an optimized desktop version of the classic PlayStation 2 action-adventure game. Experience the epic conclusion of the Jak and Daxter trilogy with improved performance, higher resolutions, widescreen support, and modern controls on Windows.

---
## 📦 What's Included

- Optimized build for Windows 10/11
- Higher resolution and widescreen support
- Improved performance and stability
- Keyboard and controller support
- Enhanced graphics settings

## ❗️ Troubleshooting
| Problem                  | Solution                                      |
|--------------------------|-----------------------------------------------|
| Game doesn't start       | Run as Administrator                          |
| Low performance          | Lower resolution or graphics settings         |
| Black screen             | Switch to Borderless Windowed mode            |
| Antivirus warning        | Add the folder to exclusions                  |
| Controller issues        | Check controller settings in game             |
